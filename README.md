# Healthcare Data Analytics Project 

## Tools Used
- SQL — Data extraction and aggregation
- Python — Data cleaning and preparation
- Tableau — Data visualization and dashboards

## Project Overview
Analysis of 897 patient records from a dental clinic
covering January 2023 to December 2024.

## Key Analysis
- Monthly patient visit trends
- Doctor performance comparison
- Treatment profitability analysis
- Financial performance tracking
- Patient demographics breakdown

## Files
- visits_clean.csv — SQL extracted data
- data_cleaning.py — Python cleaning script
- visits_ready.csv — Cleaned data for Tableau
